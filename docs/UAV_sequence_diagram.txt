title UAV Web GPS A→B — Control Service và Flight Service

participant Người_vận_hành
participant Web_Backend
participant MQTT_Broker
participant Control_Service
participant IPC_Unix_Socket
participant Flight_Service
participant Pixhawk_PX4
participant Log_JSONL

note over Control_Service,Flight_Service: Hai process độc lập. Control không mở MAVSDK; Flight là chủ duy nhất của MAVSDK/MAVLink.
note over Flight_Service,Pixhawk_PX4: PX4 chạy EKF và mọi vòng điều khiển bay. Pi quản lý FSM, mục tiêu và giám sát telemetry.

Flight_Service->>Pixhawk_PX4: Kết nối MAVSDK, đọc SYS_HITL và telemetry
Pixhawk_PX4-->>Flight_Service: mode, armed, landed, health, position
Flight_Service->>IPC_Unix_Socket: Mở /run/uav/flight.sock hoặc /tmp/uav-flight.sock
Control_Service->>MQTT_Broker: Kết nối TLS, subscribe lac/device/control
Control_Service->>Log_JSONL: SERVICE_STARTED + MQTT_CONNECTED

Người_vận_hành->>Web_Backend: Gửi nhiệm vụ và cất cánh
Web_Backend->>MQTT_Broker: payload control gồm sáu trường
MQTT_Broker->>Control_Service: lac/device/control, Retain phải OFF
Control_Service->>Control_Service: Xếp hàng; kiểm tra đủ trường, tọa độ và giới hạn payload

alt Payload không hợp lệ hoặc retained
    Control_Service->>Log_JSONL: COMMAND_REJECTED + lý do
else Lệnh hợp lệ
    Control_Service->>Log_JSONL: COMMAND_RECEIVED
    Control_Service->>IPC_Unix_Socket: command gps_start
    IPC_Unix_Socket->>Flight_Service: request JSON nội bộ
    Flight_Service->>Flight_Service: gps_plan(A, B, height, speed)

    alt Điều kiện flight không đạt
        Flight_Service-->>IPC_Unix_Socket: ok=false + lý do
        IPC_Unix_Socket-->>Control_Service: rejected response
        Control_Service->>Log_JSONL: COMMAND_REJECTED
    else Kế hoạch được chấp nhận
        Flight_Service->>Flight_Service: gps_start()
        Flight_Service->>Pixhawk_PX4: TAKEOFF/OFFBOARD hoặc PX4 Mission theo FSM
        Flight_Service->>Log_JSONL: COMMAND_ACCEPTED + trạng thái sau lệnh
        Flight_Service-->>IPC_Unix_Socket: ok=true + plan/status
        IPC_Unix_Socket-->>Control_Service: accepted response
        Control_Service->>Log_JSONL: COMMAND_ACCEPTED
        note over Web_Backend,Pixhawk_PX4: Web không nhận ACK qua MQTT; status cục bộ và telemetry mới xác nhận tiến độ.
    end
end

opt Nút điều khiển từ web
    Người_vận_hành->>Web_Backend: Tạm dừng / tiếp tục / hủy / về điểm cất cánh / LAND
    Web_Backend->>MQTT_Broker: d:pause / d:resume / d:abort / d:rtl / d:land
    MQTT_Broker->>Control_Service: lac/device/control, Retain OFF
    Control_Service->>IPC_Unix_Socket: command tương ứng
    IPC_Unix_Socket->>Flight_Service: request JSON nội bộ
    Flight_Service->>Pixhawk_PX4: Gửi lệnh hợp lệ theo FSM
    Flight_Service->>Log_JSONL: COMMAND_ACCEPTED hoặc COMMAND_REJECTED
    note over Web_Backend,Flight_Service: Không có ACK MQTT cho web; kiểm tra status và telemetry mới.
end

loop Giám sát trong khi bay
    Pixhawk_PX4-->>Flight_Service: telemetry mới và tiến độ Mission
    Flight_Service->>Flight_Service: refresh FSM, kiểm tra phase/mode/armed/landed
    Flight_Service->>Log_JSONL: phase/state thay đổi và DEBUG nếu được bật
    Control_Service->>IPC_Unix_Socket: status định kỳ
    IPC_Unix_Socket->>Flight_Service: status request
    Flight_Service-->>Control_Service: flight status
    Control_Service->>Log_JSONL: Trạng thái thay đổi và health Pi
end

alt Mission tới B
    Pixhawk_PX4-->>Flight_Service: mission finished + HOLD telemetry
    Flight_Service->>Flight_Service: GPS_COMPLETE khi telemetry xác nhận
    note over Web_Backend,Control_Service: Không publish kết quả; xem status qua client cục bộ và Gazebo/QGC.
else Mission lỗi sau khi đã bắt đầu
    Flight_Service->>Log_JSONL: lỗi/phase thực tế
    Control_Service->>Log_JSONL: Lỗi IPC nếu có
end

alt Pause / Resume / Cancel / Return Home / Return Height từ terminal Pi
    Người_vận_hành->>IPC_Unix_Socket: pi/flight/client.py gửi lệnh kỹ thuật
    IPC_Unix_Socket->>Flight_Service: request nội bộ
    Flight_Service->>Pixhawk_PX4: Action HOLD, Mission hoặc Offboard tương ứng
    Pixhawk_PX4-->>Flight_Service: ACK rồi telemetry mode/position mới
    Flight_Service-->>Người_vận_hành: trạng thái qua client
else LAND từ terminal Pi
    Người_vận_hành->>IPC_Unix_Socket: pi/flight/client.py land
    IPC_Unix_Socket->>Flight_Service: land
    Flight_Service->>Pixhawk_PX4: MAV_CMD_NAV_LAND
    Pixhawk_PX4-->>Flight_Service: ACK, LAND, ON_GROUND, armed=false theo thời gian
    note over Người_vận_hành,Pixhawk_PX4: Chờ ON_GROUND và armed=false qua status; phản hồi lệnh không xác nhận đã chạm đất.
end

alt MQTT tạm mất
    MQTT_Broker--xControl_Service: Mất liên kết
    Control_Service->>Log_JSONL: MQTT_DISCONNECTED
    Flight_Service->>Pixhawk_PX4: Tiếp tục giám sát trạng thái PX4 độc lập MQTT
    note over Control_Service,Web_Backend: Kết nối lại để nhận control mới; không phát lại lệnh bay cũ.
end

note over Người_vận_hành,Log_JSONL: flight/client.py hỗ trợ ARM/TAKEOFF/NED/GPS qua cùng socket; console.py kết nối Pixhawk trực tiếp nên không chạy cùng Flight Service trên cùng UART/UDP.
note over Control_Service,Web_Backend: Không có topic MQTT đầu ra; xem kết quả trong status và log cục bộ.
